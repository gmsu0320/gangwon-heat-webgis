# 강원지역 고령인구 폭염 취약성 Web-GIS (공개 기본틀)

강원 18개 시군 경계자료를 포함한 Streamlit 지도입니다. 추가 데이터 없이 경계가 바로 표시됩니다.

## 내 컴퓨터에서 실행

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`에 접속합니다.

## 누구나 인터넷에서 볼 수 있게 배포

1. GitHub에 새 저장소를 만듭니다. 저장소를 Public으로 설정할 경우 업로드한 파일들이 공개됩니다.
2. 압축 파일에 들어 있는 `app.py`, `requirements.txt`, `data/gangwon_18.geojson`, `.streamlit/config.toml`을 **폴더 구조 그대로** 저장소에 업로드합니다.
3. https://share.streamlit.io/ 에 로그인하고 **Create app → Deploy a public app from GitHub**를 선택합니다.
4. 저장소와 브랜치를 선택하고 **Main file path**에 `app.py`를 입력하여 Deploy합니다.
5. Streamlit이 발급한 `*.streamlit.app` 주소를 공유하면, 다른 사람도 접속할 수 있습니다. 최초 접속 시 앱이 깨어나는 시간이 발생할 수 있습니다.

참고: 도메인 `.kr` 연결은 별도 호스팅 설정이 필요할 수 있으며, 이 패키지는 Streamlit 기본 주소 공개용입니다.

## 현재 지원하는 기능
- 강원 18개 시군 경계, 시군 이름 및 코드 툴팁/팝업
- SSP 4종·2020~2090년대·가중치 A/B 선택 메뉴
- HW33 또는 TR25 CSV 임시 업로드 및 지역·시나리오·연대·값 열 연결
- 연결된 수치의 지도 색상 표시, 표와 다운로드

**아직 구현하지 않은 기능**: 가중치 A/B의 실제 취약성 지수 산정, 미래 사회인구 전망 반영, 지도 간 정량 비교. 현 단계의 메뉴 선택만으로 완성된 연구값이 계산되지는 않습니다.

## 주의
- 이 패키지에는 기후/사회 분석 CSV가 포함되지 않았습니다. 방문자가 업로드한 CSV는 그 방문자의 세션에서만 사용되고 공개 사이트의 영구 데이터로 자동 저장되지 않습니다.
- 실제 연구 결과를 모든 방문자에게 자동 표시하려면 검증된 CSV를 프로젝트 데이터 폴더에 포함시키고 `app.py`에서 자동으로 불러오게 추가 구현해야 합니다.
- 데이터 출처 표시 및 공개 가능 여부는 실제 배포 전 확인하세요.
